## ✦ About The Project

**Refokus Clone** is a frontend recreation inspired by the Refokus website.

The project was built to explore how modern creative websites combine **typography, motion, spacing, smooth scrolling, and reusable components** to create an engaging digital experience.

Rather than building only a static replica, the focus was on recreating the feel of the website through animated project showcases, continuous marquees, interactive elements, and smooth scrolling.

> **Minimal design. Bold typography. Fluid motion.**

- 🧩 **Reusable Components** — Modular React component architecture

## ✦ Components

### `Navbar`

Minimal navigation bar containing primary links and a clean call-to-action.

### `Work`

Hero section featuring oversized typography and animated project visuals.

### `Stripes`

Displays awards and recognitions in a horizontal strip layout.

### `Products`

Showcases featured projects with visuals, descriptions, and interactive elements.

### `Marquees`

Creates continuously moving logo and brand sections.

### `Cards`

Editorial-style cards used for news and project calls-to-action.

### `Footer`

Large typography, navigation links, social links, and branding complete the experience.

## ✦ Getting Started

Want to run the project locally?

### 1. Clone the repository

```bash
git clone https://github.com/yashbsl/Refokus_Clone
```

### 2. Navigate to the project

```bash
cd refokus-clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will display the local development URL in your terminal.

---

## ✦ Build For Production

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## ✦ Design Philosophy

This recreation focuses on three principles:

### Minimal × Motion × Experience

**Minimal**  
Clean layouts and intentional spacing keep the interface focused.

**Motion**  
Animations add personality and guide attention throughout the page.

**Experience**  
Typography, imagery, scrolling, and interaction work together to create an immersive interface.
